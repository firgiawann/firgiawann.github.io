Buka Web Transaksi Cek Area Akrab
“Tidak perlu buat akun. Pilih paket, scan QRIS, kuota langsung masuk!”
Alur Transaksi Otomatis (4 Langkah Bersambung)
  1. 1
    Pilih Paket Ready

    Cek varian XL Akrab, Flex, Indosat, atau Tri yang berstatus tersedia di katalog.

  2. 2
    Masukkan Nomor HP

    Ketik nomor tujuan tanpa perlu login atau mendaftar akun terlebih dahulu.

  3. 3
    Bayar QRIS (5 Menit)

    Scan kode QRIS dari e-wallet atau m-banking sesuai nominal unik transaksi.

  4. 4
    Kuota Terisi Otomatis

    Sistem memverifikasi pembayaran dan mengirim paket langsung ke nomor Anda.

Lacak Status Pesanan Saluran Info & Restock WA

Karya & Solusi Digital

Eksplorasi portofolio sistem yang saya bangun di produksi maupun repositori open-source GitHub: mulai dari web transaksi otomatis, aplikasi mobile offline-first, hingga kakas riset akademik.

“Ini beberapa proyek nyata yang sudah saya rilis dan kembangkan!”
  1. 01

    Kuotanya Awan Web & Payment Bridge

    Sistem belanja paket data otomatis tanpa registrasi akun yang terintegrasi dengan daemon pemantau mutasi QRIS realtime, kalkulasi nominal unik, cek zona area Akrab, dan bot notifikasi Telegram Admin.

    Python • FastAPI • SQLite • QRIS Daemon Kunjungi kuota.firgiawan.id
  2. 02

    Catet Uang (Offline-First Personal Finance App)

    Aplikasi pencatat keuangan pribadi bebas iklan untuk Android dan Web dengan 8 tema visual, Donut Chart pengeluaran interaktif, sistem gamifikasi 16 lencana hemat, serta rilis APK ringan teroptimasi R8/Proguard.

    Flutter • Dart • Offline-First • Web & APK
    Buka Web App Rilis APK
  3. 03

    pop-scholar-search (Academic Literature CLI & Agent Skill)

    Mesin pencari literatur ilmiah bergaya Publish or Perish 8 berbasis Python murni tanpa dependensi eksternal untuk mengeksekusi kueri ke Google Scholar, Crossref, OpenAlex, PubMed, Semantic Scholar, Lens, Scopus, dan Web of Science.

    Python • Zero-Dependency CLI • 8 Academic APIs Buka di GitHub
  4. 04

    Ruang Kognisi & PTIK Mentoring Platform

    Rangkaian web edukasi interaktif di lingkungan kampus: multimedia pembelajaran kognitif berbasis Web Speech API (Mayer Lab) serta prototipe PWA mentoring mahasiswa dengan presensi QR dinamis yang berotasi tiap 15 detik.

    firgiawan.id/ruang-kognisi • firgiawan.id/mentoring
    Ruang Kognisi Web Mentoring
  5. 05

    Mini-LMS Assignment Service & Desktop POS (LunaCaffe / SAKO)

    Implementasi microservice REST API pengelolaan tugas kuliah Sistem Terdistribusi beserta halaman tester interaktif, serta sistem Point of Sales dan antrian kantin berbasis Java 17 Swing FlatLaf & SQLite.

    PHP REST API • Java 17 Swing • MVC & SQLite Coba Tester Mini-LMS
